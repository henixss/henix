# Plano — catálogo Forma3D

## Abordagem

Site local simples, sem serviços gerenciados, para publicação gratuita no GitHub Pages. A página é estática e usa Bootstrap 5 via CDN. O catálogo é alimentado pelo array `products` em `products.js`, mantendo a inclusão de novos itens acessível para quem não quer editar a estrutura HTML.

## Estrutura

- `index.html`: estrutura semântica, navegação, hero, catálogo, processo, contato e modal de detalhes.
- `styles.css`: identidade visual, layout responsivo, ilustrações CSS e componentes.
- `products.js`: fonte de dados editável para adicionar e alterar produtos.
- `app.js`: renderização de cards, busca, filtros, modal e links do WhatsApp.
- `README.md`: instruções de manutenção e publicação no GitHub Pages.

## Design

- **Movimento:** editorial contemporâneo com influência de design industrial e estúdios de objetos.
- **Princípios:** espaço em branco generoso, contraste entre tipografia forte e detalhes monoespaçados, formas orgânicas e utilidade clara.
- **Cores:** papel quente como base; laranja queimado como cor proprietária para energia e ação; verde sálvia para comunicar materialidade e calma.
- **Layout:** composição assimétrica, com hero dividido entre manifesto e objeto abstrato; cards arejados e seções com bordas finas.
- **Assinaturas:** cantos arredondados assimétricos, microcopy em fonte mono e ilustrações de produto geradas em CSS quando não há foto.
- **Interação:** filtros e busca são imediatos; os cards são clicáveis e acessíveis por teclado; o modal concentra o próximo passo comercial.
- **Animação:** apenas elevações sutis no hover, preservando sensação de catálogo físico.
- **Tipografia:** Space Grotesk para títulos e interface; DM Mono para etiquetas, metadados e sinalização técnica.
- **Essência:** impressões 3D autorais que transformam pequenas ideias em objetos que cabem na rotina. Personalidade: tátil, autoral, direta.
- **Voz:** curta, próxima e confiante. Exemplos: “Objetos que ganham forma.” e “Uma ideia, três etapas.”
- **Marca:** círculo com monograma F3 e wordmark espaçado, reforçando precisão e processo.
- **Cor proprietária:** laranja queimado `#E66E3D`.
